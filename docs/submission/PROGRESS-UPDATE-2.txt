Milestone: the read-only ledger page is live at https://owenzhao9.github.io/flip-garden/. It reads Kuru flip-order history straight from the public Monad RPC and shows balances, flip chains, fills, fees, gas and profit or loss, with a badge that says whether the ledger matches the chain. On our own test wallet all 6 checks match the chain with a difference of 0 (cash -4.976961 USDC, coin +201 MON, gas 0.095135 MON). The page never connects a wallet or sends a transaction. The GitHub repository is now public (https://github.com/OwenZhao9/flip-garden), which replaces my earlier note that it was private. Limits: the layout has only been checked on a desktop browser, and long histories are slow to read. Next: the garden-style planting flow, with a preview and an explicit confirmation before any real order.
